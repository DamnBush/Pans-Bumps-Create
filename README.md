# Pans. Bumps. Create 2.0

Сборка на **NeoForge 1.21.1**.  
Ещё в разработке, но уже можно играть.

## Скачать
Актуальная версия — всегда здесь:  
**[Releases](../../releases/latest)**

## Что нужно
- Minecraft **1.21.1**
- **NeoForge 21.1.x**
- Оперативка: **от 6 ГБ** (лучше 8–10)

## Как поставить
1. Скачай ZIP из Releases
2. Распакуй туда, где у тебя лежат другие сборки
3. В Prism / ElyPrism / Pinecone папка обычно называется `minecraft`
4. В официальном лаунчере — чаще `.minecraft`

Не мешай моды с других сборок просто так — может разъехаться меню и конфиги.

## Если не запускается
- Проверь, что установлены Minecraft и NeoForge нужных версий.
- Выдели сборке достаточно оперативной памяти.
- Не добавляй сторонние моды без проверки совместимости.
- Не переноси старые options.txt, конфиги или сохранения, если это не требуется.
- Если ошибка повторяется, приложи logs/latest.log и, если он появился, файл из папки crash-reports.



## Полезные клавиши

- **F6** — переключение отображения тела игрока и руки при виде от первого лица.
- **Точка на цифровом блоке клавиатуры (Numpad `.`)** — скрыть или показать индикатор прокачки PMMO в левом верхнем углу экрана.

Если клавиша не работает, проверь назначение в настройках управления Minecraft: её может занимать другой мод или она может конфликтовать с другой клавишей.
